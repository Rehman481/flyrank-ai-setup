## Overview

This repository documents my work for the FlyRank AI Internship. It focuses on AI-assisted software development, Git best practices, and Node.js fundamentals using Cursor AI as a development partner.

## Tech Stack

- Node.js
- Git
- Cursor AI

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or later
- [Git](https://git-scm.com/)

### Installation

```bash
git clone https://github.com/Rehman481/flyrank-ai-setup.git
cd flyrank-ai-setup
npm install
```

> Application code and scripts are coming soon. The repository is currently in an early setup phase.
